# HackMate

Discover technology events and build teams across Algerian universities. This is an early development preview; registration, verification and team UI are not yet available.

## Setup
Node 22+, npm install, copy .env.example to .env.local, configure Supabase URL and publishable key, then npm run dev. Run npm run lint, npm run typecheck, npm test, npm run build before release. Never commit secrets. Public events require approved moderation status and RLS.
